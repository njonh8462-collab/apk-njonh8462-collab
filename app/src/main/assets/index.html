    📖 راهنمای کامل
    1. توکن GitHub بسازید و آن را بررسی کنید.
    2. فایل HTML یا ZIP را بارگذاری کنید.
    3. آیکون دلخواه را از بین ۶ طرح زیبا انتخاب کنید یا آیکون سفارشی بدهید.
    4. زبان برنامه‌نویسی را انتخاب کنید (Java یا C++ با JNI).
    5. تنظیمات اپ را وارد کنید.
    6. روی «ساخت خودکار APK» کلیک کنید.
    7. ۳ تا ۱۰ دقیقه صبر کنید تا APK دانلود شود.
    ℹ️ تفاوت Java و C++ (JNI)
    • Java: سبک‌ترین و سازگارترین گزینه. برای ۹۹٪ اپ‌های وب کافی است.
    • C++ (JNI): یک لایه native C++ به اپ اضافه می‌کند که از طریق JNI با Java ارتباط دارد. برای اپ‌هایی که نیاز به پردازش سنگین (رمزنگاری، پردازش تصویر، بازی‌سازی) دارند مناسب است. حجم APK کمی بیشتر می‌شود و build کمی طولانی‌تر.
